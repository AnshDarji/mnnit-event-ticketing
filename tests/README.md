# Testing Guidelines

The MNNIT Event Ticketing platform utilizes automated integration and end-to-end (E2E) testing suites.

## Test Suites
- **Backend Tests:** API route and authentication verification.
- **Frontend & E2E Tests:** Playwright-driven user flow validation (booking tickets, event discovery, check-in).

Run tests locally prior to submitting pull requests to ensure no regressions are introduced.
