# Infrastructure & Deployment Overview

This directory contains configuration files required for containerization and deployment of the MNNIT Event Ticketing platform.

## Architecture Components
- **Docker Compose (`docker-compose.yml`):** Orchestrates local multi-container development for the frontend, backend, and PostgreSQL database.
- **Render Configuration (`render.yaml`):** Defines cloud deployment specifications and service definitions.
- **Environment Management (`.env.example`):** Reference template for required configuration keys.
